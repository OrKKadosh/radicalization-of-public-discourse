# **Automated Propaganda Spreading System**  

## **Overview**  
This project demonstrates how **Twitter bots** and **GPT-3.5 API** can automate propaganda spreading and radicalize public discourse. Using staged content escalation, the system mimics real-world manipulation tactics.  

---

## **Features**  
- **Bot Network**: 5 bots with unique profiles and ideologies.  
- **Tweet Automation**: Generates and posts tweets 3x daily using real news and GPT-3.5.  
- **Content Escalation**: Gradual increase in extremism over **5 stages** (10 days each).  
- **Impact**: Achieved up to **8,000 views**, **170 retweets**, and **600 likes** on key tweets.  

---

## **Technologies**  
- **Python**  
- **OpenAI GPT-3.5**  
- **Twitter API**  
- **NewsAPI**  

---

## **How It Works**  
1. **Fetch News**: Gather relevant U.S. political news.  
2. **Generate Tweets**: Use GPT-3.5 to create ideology-aligned content.  
3. **Automate Posting**: Schedule tweets at intervals.  
4. **Escalate Content**: Increase extremism over time.  

---

## **Challenges**  
- API restrictions (Twitter, GPT-3.5).  
- Limited cloud resources for scaling.  
- Content duplication issues.
